# Демо-аккаунты

Все данные и телефонные номера ниже вымышленные и предназначены только для
локальной демонстрации. Перед запуском seed задайте значения паролей в `.env`;
пароли не хранятся в этом документе или в `.env.example`.

| Роль | Учётная запись | Телефон для входа | Переменная пароля |
|---|---|---|---|
| Студент | `student.alpha` | `+7 900 000-00-01` | `SEED_ALPHA_PASSWORD` |
| Студент | `student.beta` | `+7 900 000-00-02` | `SEED_BETA_PASSWORD` |
| Студент | `test.seed.01` | `+7 900 000-10-01` | `SEED_TEST_STUDENTS_PASSWORD` |
| Студент | `test.seed.02` | `+7 900 000-10-02` | `SEED_TEST_STUDENTS_PASSWORD` |
| Студент | `test.seed.03` | `+7 900 000-10-03` | `SEED_TEST_STUDENTS_PASSWORD` |
| Студент | `test.seed.04` | `+7 900 000-10-04` | `SEED_TEST_STUDENTS_PASSWORD` |
| Студент | `test.seed.05` | `+7 900 000-10-05` | `SEED_TEST_STUDENTS_PASSWORD` |
| Студент | `test.seed.06` | `+7 900 000-10-06` | `SEED_TEST_STUDENTS_PASSWORD` |
| Сотрудник | `staff.demo` | `+7 900 000-20-01` | `SEED_STAFF_PASSWORD` |
| Сотрудник | `staff.other` | `+7 900 000-20-02` | `SEED_STAFF_PASSWORD` |
| Сотрудник | `staff.manager` | `+7 900 000-20-03` | `SEED_STAFF_PASSWORD` |

Номер можно вводить с пробелами, скобками и дефисами. Российские варианты,
начинающиеся на `+7`, `7` или `8`, приводятся к одному международному виду.
Аккаунты, созданные до привязки телефона, по-прежнему могут входить по прежнему
логину и паролю; номера и логины используют общий экран соответствующей роли.

Чтобы подготовить демо-данные:

1. Скопируйте `.env.example` в `.env` и задайте перечисленные переменные
   паролей.
2. Примените миграции: `npx prisma migrate dev`.
3. Выполните `npx prisma db seed`.

Seed пересоздаёт управляемые им тестовые аккаунты и связанные фикстуры в одной
транзакции, поэтому повторный запуск не создаёт дубликаты. При этом он
сбрасывает сделанные вручную изменения в этих демо-данных; не запускайте его
для обычного обновления пароля или на production-базе.
