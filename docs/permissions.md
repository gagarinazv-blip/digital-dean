# Матрица прав MVP

Роль берётся только из действующей серверной сессии. Идентификаторы студента и
сотрудника для проверок берутся из связанных с этой сессией профилей, а не из
адреса страницы, формы или браузера.

| Роль | Ресурс | Чтение | Создание | Изменение статуса | Назначение |
| --- | --- | --- | --- | --- | --- |
| Студент | Заявки | Только свои | Только от своего имени | Нет | Нет |
| Студент | Расписание | Только своей группы | Нет | Нет | Нет |
| Студент | Оценки | Только свои | Нет | Нет | Нет |
| Студент | Дедлайны и материалы | Только свои | Нет | Только личный статус и чек-лист | Нет |
| Студент | Профиль студента | Только свой | Нет | Нет | Нет |
| Студент | Возможности | Только опубликованные; заявки только свои и не черновые | Подать заявку на опубликованную возможность | Отозвать только свою заявку | Нет |
| Студент | Пользователи | Нет | Нет | Нет | Нет |
| Сотрудник | Студенты | Нет | Создать учётную запись и задать пароль | Изменять разрешённые поля и пароль, сбрасывать доступ | Нет |
| Сотрудник | Заявки | Назначенные ему и неназначенные разрешённого типа | Нет | Только свои назначенные, по допустимым переходам | Может взять разрешённую неназначенную заявку себе |
| Главный сотрудник (`staff.manager`) | Виды справок | Все, включая черновики и архив | Создавать и дублировать | Редактировать, публиковать, архивировать; удаления нет | Нет |
| Сотрудник | Виды справок | Нет | Нет | Нет | Нет |
| Студент | Виды справок | Только активные | Нет | Нет | Нет |
| Сотрудник | Расписание | Нет | Нет | Нет | Нет |
| Сотрудник | Оценки | Нет | Нет | Нет | Нет |
| Сотрудник | Профиль студента | Нет | Нет | Нет | Нет |
| Сотрудник | Пользователи | Нет | Нет | Нет | Нет |
| Сотрудник | Возможности | Все, включая черновики | Создавать возможности | Редактировать, публиковать, архивировать и удалять через серверные actions | Нет |
| Сотрудник | Заявки на возможности | Все заявки | Нет | Менять статус и комментарий в Staff-разделе | Нет |

Когда сотрудник открывает заявку, ему доступны только ФИО автора, группа и
курс, необходимые для работы с этой заявкой. Это не даёт доступ к профилю
студента как к отдельному ресурсу. В отдельном разделе «Студенты» сотрудники
могут искать студентов, создавать учётные записи, задавать и сбрасывать пароль,
а также изменять разрешённые профильные поля. Пароль студенческого кабинета
сохраняется только в виде хеша, а сотрудник не может его прочитать. Смена
телефона и сброс доступа завершают активные сессии; смена телефона требует
подтверждения. Сотрудники могут задать пароль корпоративной почты, но не могут
его прочитать: он хранится зашифрованным. Изменения записываются в журнал без
значений полей и паролей. Чтение паролей и произвольный доступ к сессиям
запрещены.

Разрешённые типы заявок заданы в
[`src/lib/permissions.ts`](../src/lib/permissions.ts). Сейчас у обоих учебных
отделов в демонстрационных данных разрешён тип «Справка». Неописанный отдел не
получает разрешений на неназначенные заявки.

Проверки выполняются серверными функциями из
[`src/lib/permissions.ts`](../src/lib/permissions.ts), серверными guards и
запросами, ограниченными текущим профилем. Скрытие кнопки само по себе не
считается проверкой доступа.

Виды справок защищает `requireCertificateFormManager` в
[`src/app/staff/certificate-forms/actions.ts`](../src/app/staff/certificate-forms/actions.ts):
источник запроса, серверная сессия и `isManagerAccount` из `requireStaffContext`
проверяются в каждом действии. Создание, правка, копирование и смена статуса
записываются в `CertificateFormAuditLog`. Заявка хранит снимок схемы и её версию,
поэтому правка вида справки не меняет поданные заявки.
