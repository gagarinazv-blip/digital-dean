# Матрица прав MVP

Роль берётся только из действующей серверной сессии. Идентификаторы студента и
сотрудника для проверок берутся из связанных с этой сессией профилей, а не из
адреса страницы, формы или браузера.

| Роль | Ресурс | Чтение | Создание | Изменение статуса | Назначение |
| --- | --- | --- | --- | --- | --- |
| Студент | Заявки | Только свои | Только от своего имени | Нет | Нет |
| Студент | Расписание | Только своей группы | Нет | Нет | Нет |
| Студент | Оценки | Только свои | Нет | Нет | Нет |
| Студент | Профиль студента | Только свой | Нет | Нет | Нет |
| Студент | Пользователи | Нет | Нет | Нет | Нет |
| Сотрудник | Заявки | Назначенные ему и неназначенные разрешённого типа | Нет | Только свои назначенные, по допустимым переходам | Может взять разрешённую неназначенную заявку себе |
| Сотрудник | Расписание | Нет | Нет | Нет | Нет |
| Сотрудник | Оценки | Нет | Нет | Нет | Нет |
| Сотрудник | Профиль студента | Нет | Нет | Нет | Нет |
| Сотрудник | Пользователи | Нет | Нет | Нет | Нет |

Когда сотрудник открывает заявку, ему доступны только ФИО автора, группа и
курс, необходимые для работы с этой заявкой. Это не даёт доступ к профилю
студента как к отдельному ресурсу. Сотрудник не видит пароли, сессии и других
пользователей. Создание и удаление пользователей запрещены.

Разрешённые типы заявок заданы в
[`src/lib/permissions.ts`](../src/lib/permissions.ts). Сейчас у обоих учебных
отделов в демонстрационных данных разрешён тип «Справка». Неописанный отдел не
получает разрешений на неназначенные заявки.

Проверки выполняются серверными функциями из
[`src/lib/permissions.ts`](../src/lib/permissions.ts), серверными guards и
запросами, ограниченными текущим профилем. Скрытие кнопки само по себе не
считается проверкой доступа.
